# ClinPaper 科研绘图工作台功能说明

## 一、功能定位

ClinPaper 科研绘图工作台用于将用户提供的医学资料转换为结构化、可编辑的机制图、诊疗路径图、比较图、概念框架图和研究进展时间线。

当前原型基于 VISTA 的结构提取、布局计算与 Draw.io 导出能力实现。它与 NanaDraw 的图片生成模式相互独立：

- 结构化矢量模式用于机制链、诊疗路径、比较矩阵、概念框架和时间线；
- 图片生成模式用于机制图、图形摘要和复杂医学插画。

## 二、当前已实现流程

1. 用户选择叙述性综述图形模板；
2. 用户输入图形标题和去标识化后的医学资料；
3. 系统按模板附加事实与证据边界；
4. 任务进入本地顺序队列；
5. 文本模型提取图形结构并规划布局；
6. VISTA 计算节点位置、容器和连线路径；
7. 系统生成可编辑 Draw.io 文件；
8. 已安装 Draw.io 时生成 PNG 预览和 SVG；
9. 用户可下载单个格式或全部文件。

开启视觉复核后，系统还会使用多模态模型检查节点重叠、箭头穿过节点、连线交叉和文字溢出，并对 Draw.io 源文件进行有限轮次的修正。

## 三、当前叙述性综述模板

### 1. 疾病机制图

用于展示病因或触发因素经分子通路、细胞过程和组织变化导致疾病表型的机制链。需区分激活、抑制、反馈、相关和尚未明确的关系。

### 2. 诊疗路径图

用于展示特定临床场景中从初始评估、诊断依据和风险分层到治疗分支、监测与复评的决策路径。

### 3. 治疗策略比较图

用于按适用人群、作用机制、疗效、安全性、优势和局限等统一维度并列比较多种治疗策略。不自行生成排名或确定性推荐。

### 4. 概念框架图

用于围绕核心研究问题组织关键概念、情境、作用过程、主要结局和证据缺口，并保留不同关系类型。

### 5. 研究进展时间线

用于按年份或时期梳理某一主题的关键发现、技术变化、临床证据与转化里程碑。不自行补充缺失时间或夸大单篇研究的意义。

五类模板均会将“模板将提取”中的专属结构要求写入生成提示词，并在页面中展示。综述中的医学事实和主要观点应来自用户提供且已核对的外部文献证据。

## 四、页面与字段

### 1. 工作台主页面

- 医学模板；
- 图形标题；
- 医学资料；
- 模板将提取的专属结构；
- 模板对应的事实与证据边界；
- 模板提示词统一管理入口；
- 生成结构化矢量图；
- 任务队列；
- 结果预览和导出入口。

### 2. API 配置弹窗

- 文本模型 API 地址；
- 文本模型名称；
- 文本模型 API Key；
- 是否启用视觉复核；
- 视觉模型 API 地址；
- 视觉模型名称；
- 视觉模型 API Key；
- 是否生成 PNG 预览；
- 测试连接；
- 保存配置。

API Key 只保存在当前电脑的本地配置文件中，不在前端接口返回完整值。

### 3. 模板提示词弹窗

- 从页面顶部“模板提示词”进入；
- 可在同一弹窗中切换疾病机制图、诊疗路径图、治疗策略比较图、概念框架图和研究进展时间线；
- 显示当前使用的完整实际提示词，并标记为“默认提示词”或“已自定义”；
- 提示词必须保留 `{{title}}` 和 `{{user_text}}`，分别用于注入图形标题和用户的医学资料；
- “保存并应用”将自定义提示词保存到当前电脑，之后新建的对应模板任务直接使用该内容；
- “恢复默认”删除对应模板的本地自定义内容，恢复使用由模板结构、图形要求和事实边界组成的系统默认提示词；
- 每个任务创建时都会在任务目录的 `prompt.md` 中保存当次实际使用的提示词快照，后续修改不回溯影响已创建任务。

## 五、任务状态

- 排队中；
- 生成中；
- 已完成；
- 失败；
- 已取消。

生成中的阶段包括读取资料、提取图形结构、规划版式、计算节点和连线、生成预览与导出、视觉复核。

失败时优先向用户展示可执行的中文原因，例如配置缺失、鉴权失败、额度不足、响应超时、模型未返回结构化结果、网络错误或 Draw.io 不可用；原始日志保留在任务详情中。

## 六、导出

- Draw.io：主要的可编辑源文件，文字、节点和连线可继续修改；
- SVG：适合矢量排版和投稿，但不同编辑软件的元素级编辑能力不同；
- PNG：用于预览和快速插入文档；
- ZIP：包含当前任务的主要导出文件、结构化中间结果和输入文本。

## 七、当前边界

- 当前为本地产品原型，未实现账号、权限、团队协作、云端任务和对象存储；
- 当前队列在一个本地进程内按顺序执行；
- VISTA 上游仓库的商业使用授权尚未确认，当前仅用于本地研究和产品验证；
- 系统生成结果不能替代医学核对，用户仍需检查事实、数值、关系、引用和隐私信息；
- 正式接入 ClinPaper 线上产品前，需补充授权确认、服务隔离、密钥托管、任务持久化、审计和安全策略。
