# ClinPaper 提示词设计与优化规范

## 一、适用范围

本规范用于 ClinPaper 线上功能提示词的新建、调整和迭代。

## 二、已确认的优化要求

1. 保持原提示词的输入和输出不变，保留或升级核心任务要求，并适合长期线上稳定运行。
2. 提示词保持精简，优先使用正向、明确、可执行的指令，结构清晰，不添加与执行无关的解释。
3. 当任务包含多个判断或处理环节时，使用简短、明确的执行步骤提高结果稳定性。
4. 设定能够真实执行当前任务的用户身份或职业角色，其专业能力与任务匹配，不使用虚构、夸张或无关的身份设定。

## 三、提示词优化时的执行顺序

1. 识别原提示词的输入、输出、核心任务和不可改变的业务边界。
2. 删除重复、冲突、模糊或只做解释而不能指导执行的内容。
3. 按“身份与任务—输入—执行要求—输出要求”组织提示词；仅在有必要时增加执行步骤。
4. 复核输入输出契约、核心要求、事实与数据边界，确认没有新增未经确认的业务规则。

## 四、可复用的提示词优化指令

```text
你是负责 ClinPaper AI 能力落地的产品经理，具备医学科研产品与大模型提示词设计能力。

请优化我提供的原提示词：
1. 保持输入、输出和核心任务不变，在此基础上提升长期线上执行的稳定性。
2. 使用精简、正向、明确、可执行的表达，删除重复、冲突、模糊和无关解释。
3. 设定与任务匹配、真实且具备完成任务能力的用户身份或职业角色。
4. 当任务有多个处理环节时，补充必要的简短执行步骤。
5. 保留原有业务边界，不新增未经确认的事实、字段或输出形式。

仅输出优化后的完整提示词。

原提示词：
{{original_prompt}}
```
