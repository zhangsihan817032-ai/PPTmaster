# ClinPaper 产品知识库使用说明

本目录用于沉淀 ClinPaper 的产品知识，供后续 Codex 任务读取。

开始任务前：

1. 先阅读[《ClinPaper项目背景与产品目标》](ClinPaper项目背景与产品目标.md)了解产品定位和通用原则。
2. 涉及新建或优化提示词时，再阅读[《ClinPaper提示词设计与优化规范》](ClinPaper提示词设计与优化规范.md)。
3. 涉及正文选中文本后的润色、改写或精简时，再阅读[《ClinPaper正文局部AI编辑功能说明》](ClinPaper正文局部AI编辑功能说明.md)。
4. 涉及查文献时，再阅读[《ClinPaper查文献功能说明》](ClinPaper查文献功能说明.md)。
5. 涉及医学综述时，再阅读[《ClinPaper综述功能说明》](ClinPaper综述功能说明.md)。
6. 涉及病例报告时，再阅读[《ClinPaper病例报告功能说明》](ClinPaper病例报告功能说明.md)。
7. 涉及临床研究时，再阅读[《ClinPaper临床研究功能说明》](ClinPaper临床研究功能说明.md)。
8. 涉及界面规范时，按任务需要读取 dui-kit 目录中的对应资料。

记录与产出规则：

- 默认使用中文和产品语言，说明功能目的、流程、页面、字段、状态与交互。
- 用户未明确要求时，不输出体验问题、优先级或优化建议。
- 线上未确认的内容不得写成既有事实；需要区分“已确认”和“待后续补充记录”。
- 不在知识库中记录真实患者资料、既有病例正文、账号信息或可识别个人身份的信息。
- 病例事实与外部文献证据必须分开描述，外部文献不得替代病例事实。
- 临床研究的方法、样本量、统计结果、效应值、置信区间和 P 值必须来自当前研究资料，不得由外部文献或 AI 补写。
- 医学综述中的医学事实和主要观点应有适用的外部文献支持，用户输入用于定义任务，不能替代医学证据。
- 查文献的召回结果和智能分析只代表当前检索文献批次，文献在进入正文前仍需核对研究对象、场景、结局和证据边界。
- 润色、改写和精简只处理用户当前选中的正文，并根据论文类型保护文献证据、患者事实或当前研究数据，不得因语言调整改变事实、数值、结论方向和引用关系。
- 完成功能新增或交互变更后，同步更新对应产品知识库文档。
